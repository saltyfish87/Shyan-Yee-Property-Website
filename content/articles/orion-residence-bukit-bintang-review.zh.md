# 一句话结论：谁适合买 Orion Residence？

**我的看法。** Orion 是我在武吉免登走过最精品的一个：46 层只有 298 个单位，走去 Pavilion KL 大约 3 分钟、去 TRX 8 分钟，邻居是 JW 万豪和威斯汀。整个项目是照酒店式生活做的——劳斯莱斯专车服务、住户专用保险库、订制珠宝服务，还有一部户外玻璃观景电梯，这个我在这一带没看过第二个。交楼是拎包入住；我拍的样板房里，大理石地板、Gaggenau 和 Bosch 家电、家具、窗帘、灯，全部在配套里，拿钥匙进来看到的就是这样。最大的间隔是 1,329 尺的双钥匙，两房加一个有独立门的 studio；要更大的话，销售可以把两个单位打通。这些东西你是用每个月的管理费在付，所以它适合要一间现成的、有服务的市区永久地契房子的人，不适合要压低持有成本的人。

- **适合：** 想要现成、附家具的永久地契单位，步行可到 Pavilion KL 和武吉免登 MRT 的买家；看重户数少和私密性的业主。
- **请三思：** 介意每平方英尺 RM 1.32 月费的人；需要大户型家庭格局的人。

# Orion Residence 在哪里？步行可到什么？

Orion 位于 Jalan Bukit Bintang 旁的 Jalan Gading。最近的商场是 The Starhill、Pavilion KL 和 Lot 10，武吉免登 MRT 和单轨火车站都很近。Suria Mall 约 2.9 公里，Prince Court 医疗中心 1.2 公里，隔壁就是 TRX。

# 服务与设施

五个主题设施区（The Galactic、The Aquarius、The Cosmos、The Aurora、The Constellation）、顶楼空中休息室、Moon Bar 和可看市景的餐饮空间。有两项少见的配置：自动化代客泊车系统，以及由瑞士保安公司管理的私人保险库服务。
